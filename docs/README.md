# Shadow CLI documentation

Shadow uses Snowfall as its default terminal. It adds direct subscription connections, reliable
onboarding, trusted local security harness add-ons, and self-hosted model profiles while retaining
recoverable jobs, artifacts, consultation, and collaboration presets. Start with the
[terminal contract](TERMINAL_RENDERERS.md) and [collaboration guide](COLLABORATION.md).
